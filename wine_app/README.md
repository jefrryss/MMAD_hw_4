# Подборка хороших вин

Приложение оценивает вероятность того, что оценка вина не ниже 7. Проверено на Python 3.13.5. Версии библиотек зафиксированы в `requirements.txt`.

## Запуск

Откройте терминал в папке `wine_app`:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В Windows вместо `source .venv/bin/activate` выполните `.venv\Scripts\activate`.

Также можно запустить приложение из другой папки, передав полный путь к `app.py`. Данные читаются относительно файла приложения.

## Возможности

- Ввод 12 признаков и оценка одного вина.
- Матрица ошибок, precision, recall, F1, ROC- и PR-кривые с текущим порогом.
- Загрузка CSV, проверка признаков и скачивание предсказаний.
- Диаграмма коэффициентов модели после масштабирования.

Порог в сайдбаре общий для всех вкладок. По умолчанию используется значение из `config.json`. Цвет вина задаётся в `is_red`: 1 — красное, 0 — белое. Для загрузки CSV можно скачать пример во вкладке «Пакетное предсказание».

## Модель

`model.joblib` содержит весь пайплайн `StandardScaler → LogisticRegression`, обученный без весов классов на полной тренировочной выборке. В приложении модель не обучается. Порог 0.286550 выбран по максимуму F1 на валидации; тест не использовался для выбора порога.

На тесте: precision = 0.4574, recall = 0.6205, F1 = 0.5266, ROC-AUC = 0.8209, AP = 0.4848. В `test.csv` сохранены 1596 объектов, целевая переменная — `target`.

## Кэширование

`st.cache_resource` хранит один общий объект модели: он не перечитывается из файла при каждом действии пользователя. `st.cache_data` используется для таблицы и массива тестовых вероятностей; данные сериализуются и возвращаются как отдельные копии.

В функции `test_proba(_model, X)` аргумент `_model` исключён из хеширования. Порог не является аргументом этой функции, поэтому движение ползунка не запускает `predict_proba` заново для теста. Меняются только метки и зависящие от порога метрики. Без декоратора `joblib.load` перечитывал бы модель при каждом перезапуске скрипта.
